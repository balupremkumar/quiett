Quiett brand candidates — P2 pick

Three icon directions, two wordmark treatments. Violet on dark (#BFA8FF → #7C5CFF, gradient, product-inside accent) plus a monochrome tray glyph for each icon — checked at 16 / 32 / 256px against both a dark and a light Windows 11 taskbar. No text baked into any icon. Pick one icon direction and one wordmark treatment (or ask for a mix) — that's the P2 gate.

Wordmarks

A · Geometricquiett, lowercase

Idea: quiet, geometric, lowercase, tracked out a touch — recedes so the product does the talking, not the logo. Font stack (honest, no outline conversion done): Century Gothic / Poppins / Segoe UI Variable Display Semibold, weight 600. Will render slightly differently machine to machine until a picked weight is converted to paths.

B · Double-t waveformQuie + drawn "tt"

Idea: the double "t" becomes the icon's own waveform — its crossbar rebuilt as a 3-bar peak, so the one word that means "quiet" carries the mark. "Quie" is live text (same honest font stack as A); the "tt" is hand-drawn and its kerning against the text is eyeballed for this mockup, not measured.
